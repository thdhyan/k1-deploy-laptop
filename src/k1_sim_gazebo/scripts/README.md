# src/k1_sim_gazebo/scripts

Part of [k1-deploy-laptop](https://github.com/thdhyan/k1-deploy-laptop).

| File | What it does |
|---|---|
| `mujoco_fleet_node.py` | MuJoCo fleet node — N K1 robots, one physics world each, ROS2 namespaced. |
| `mujoco_fleet_policy.py` | 6-robot K1 fleet with trained velocity policy — MuJoCo, video recording. |
| `mujoco_fleet_video.py` | Stable 6-robot K1 fleet demo — MuJoCo, video recording, fleet command test. |
| `mujoco_robocup_demo.py` | RoboCup 3v3 K1 demo on a soccer field — MuJoCo backend, CPU physics. |
| `mujoco_stereo_capture.py` | K1 stereo head capture — ZED 2i replica in MuJoCo (CPU). |
